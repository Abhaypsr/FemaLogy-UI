# FemaLogy UI

A minimal Vite + React starter for the FemaLogy project.

Quick start

```bash
npm install
npm run dev
```

Build

```bash
npm run build
npm run preview
```

Files

- `package.json`: project metadata and scripts
- `vite.config.js`: Vite config
- `index.html`: app entry
- `src/`: React source files

If you want, I can add TypeScript, ESLint, or a CI workflow next.
